### 3. BULLETPROOF PRODUCTION BUILD & SHARED HOSTING ARCHITECTURE (CRITICAL!)
When standard Vite/Rollup bundles `onnxruntime-web`, `@imgly/background-removal`, or `@huggingface/transformers`, minification mangles internal WASM/WebGPU exports (causing `TypeError: (...).webgpuInit is not a function` and `no available backend found` in production). You MUST prevent this completely by implementing ALL of the following rules:

1. **Bypass Vite Bundling via Native Runtime ESM CDN Loader**:
   - NEVER let Vite/Rollup bundle or minify `@imgly/background-removal`, `@huggingface/transformers`, `onnxruntime-web`, or `@gradio/client`. Do NOT list heavy AI packages in `package.json` if not needed, or strictly externalize/exclude them.
   - Load them dynamically at runtime in the browser using an un-bundled native dynamic import helper:
     `const importModule = new Function('url', 'return import(url)');`
2. **Pre-Generate `.htaccess` & `coi-serviceworker` Automatically into `public/`**:
   - Create `public/.htaccess` inside the project so that when Vite runs `npm run build`, `.htaccess` is automatically copied inside the `dist/` folder! Configure `public/.htaccess` with:
     ```apache
     <IfModule mod_headers.c>
       Header set Cross-Origin-Opener-Policy "same-origin"
       Header set Cross-Origin-Embedder-Policy "credentialless"
       Header set Access-Control-Allow-Origin "*"
     </IfModule>
     <IfModule mod_mime.c>
       AddType application/wasm .wasm
       AddType text/javascript .mjs
     </IfModule>
     <IfModule mod_rewrite.c>
       RewriteEngine On
       RewriteBase /
       RewriteRule ^index\.html$ - [L]
       RewriteCond %{REQUEST_FILENAME} !-f
       RewriteCond %{REQUEST_FILENAME} !-d
       RewriteRule . /index.html [L]
     </IfModule>
     ```
     *(Using `credentialless` unlocks multi-threaded WASM `SharedArrayBuffer` speed on Hostinger while keeping Google AdSense & external CDN assets 100% unblocked!)*
3. **Configure `vite.config.ts` for Universal Deployment**:
   - Set `base: './'` so `dist` works in root `public_html` OR any subdirectory without broken asset paths.
   - Set `worker: { format: 'es' }` and `optimizeDeps: { exclude: ['@imgly/background-removal', '@huggingface/transformers', 'onnxruntime-web', '@gradio/client'] }`.
